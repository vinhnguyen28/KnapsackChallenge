Cách chơi

Chỉ bốn bước là bạn đã vào trận.

  1. Tải file .zip bằng nút tải game bên dưới.
  2. Giải nén ra một thư mục bất kỳ (bấm chuột phải, chọn Extract All).
  3. Mở KnapsackChallenge.exe để bắt đầu.
  4. Chọn vật phẩm sao cho tổng cân nặng không vượt sức chứa và tổng giá trị cao nhất.

Câu hỏi thường gặp

Windows báo “Windows protected your PC” thì sao?

Đây là cảnh báo chung cho phần mềm chưa có chứng chỉ ký số. Bấm “More info”, rồi “Run anyway”. Bạn có thể tự đọc mã nguồn ở trên để yên tâm.

Game báo thiếu .NET?

Cài .NET Desktop Runtime từ trang chính thức của Microsoft rồi mở lại game.

Game có chạy trên macOS hay Linux không?

Chưa. WPF chỉ chạy trên Windows.

Tôi muốn góp ý hoặc báo lỗi?

Mở một Issue trên trang GitHub của dự án.
