Game này có gì?

Bài toán cái túi (Knapsack) nổi tiếng trong lập trình, được làm thành trò chơi trực quan để ai cũng chơi được. Một file cài đặt duy nhất, tải về, bấm đúp và chơi.

Cách chơi

Chỉ ba bước là bạn đã vào trận.

  1. Tải file cài đặt KnapsackChallenge-Setup.exe bằng nút tải game.
  2. Bấm đúp vào file để cài đặt. Nếu Windows báo “Windows protected your PC”, bấm More info rồi chọn Run anyway.
  3. Mở game và chọn vật phẩm sao cho tổng cân nặng không vượt sức chứa mà tổng giá trị cao nhất.

Câu hỏi thường gặp

Windows báo “Windows protected your PC” thì sao?

File cài đặt chưa có chứng chỉ ký số doanh nghiệp nên Windows SmartScreen cảnh báo. Bấm “More info”, rồi “Run anyway” để cài bình thường. Bạn có thể tự đọc mã nguồn ở trên để yên tâm.

Cần Internet để chơi không?

Chế độ nhiều người chơi, đăng nhập và lưu điểm cần kết nối Internet tới máy chủ. Chế độ một người chơi dùng để luyện tập thuật toán Balo.

Game có chạy trên macOS hay Linux không?

Chưa. WPF chỉ chạy trên Windows.
